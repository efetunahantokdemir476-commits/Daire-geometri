Alan İspat Animasyonu
Daire n dilime bölünüp yeniden dizilince → dikdörtgen oluşur.
Genişlik = ½ · 2πr = πr, Yükseklik = r → Alan = πr²
Tanım & Formüller

Daire: Bir düzlemde merkeze eşit uzaklıktaki noktaların oluşturduğu kapalı bölgedir. r yarıçap, d = 2r çap olarak gösterilir.

A = π · r²
Daire Alanı
C = 2π · r = π · d
Çember Çevresi
r = √(A/π)
Alandan Yarıçap
📋 ÖSYM'de Çıktı

Çevre/Alan oranı: C/A = 2/r. İki dairenin alanları oranı = yarıçaplar oranının karesi: A₁/A₂ = r₁²/r₂². Çevre oranı = yarıçaplar oranı.

Dilimleri almaşık olarak ters çevirerek yan yana diz. n → ∞ olunca bir dikdörtgen oluşur.

4

İşte bu yüzden daire alanı πr²'dir! ✓

Daire kesiti (circular segment): Bir kiriş ile o kirişin karşısındaki yay arasında kalan bölge. d = merkezden kirişe uzaklık.

cos(α/2) = d/r
Yarı açı → uzaklık ilişkisi
k = 2√(r²-d²)
Kiriş Uzunluğu
A_kesit = A_dilim - A_üçgen
Kesit Alanı
A = r²·arccos(d/r) - d√(r²-d²)
Tam Kesit Alanı
📋 ÖSYM'de Çıktı

Kiriş-merkez uzaklık soruları: r² = d² + (k/2)². Çaplara dik kiriş = kirişi ikiyer. Çap tüm kirişlerin en büyüğüdür.

İspat Adımları
1
Kiriş & merkez uzaklık
Merkez O, kiriş AB. Merkezden kirişe dik çizilir. Dik uzaklık = d. Pithagoras:
r² = d² + (k/2)²
2
Merkez açısını bul
Yarım kiriş = √(r²-d²). Merkez yarı açısı:
cos(α/2) = d/r
α = 2·arccos(d/r)
3
Dilim alanı
α açılı dilim alanı:
A_dilim = (α/2π)·πr² = ½r²α
4
Üçgen alanı
OAB üçgeni: taban = kiriş = 2√(r²-d²), yükseklik = d
A_üçgen = d·√(r²-d²)
5
Kesit = Dilim - Üçgen
A_kesit = ½r²α - d√(r²-d²)
Burada α = 2·arccos(d/r) radyan. ✓

Teğet Uzunluğu
📋 ÖSYM'de Çıktı

Teğet-kiriş açısı = ½ yay çok sık. Dış noktadan iki teğet: OPA üçgeni dik açılı (P'de). Güç teoremi: kiriş parçaları çarpımı eşit.

İspat: Teğet ⊥ Yarıçap
1
Teğet noktası T
Çember üzerinde T noktasına teğet çiziyoruz. OT yarıçapını çiziyoruz. İddia: OT ⊥ teğet.
2
Çelişki ile ispat
OT'nin teğete dik olmadığını varsay. O zaman teğet üzerinde T'den farklı bir Q noktası vardır ki OQ < OT = r.
3
Çelişki
OQ < r olduğundan Q çemberin içindedir. Ama teğet çemberi sadece T'de keser. Q aynı zamanda teğet üzerinde → çelişki!
4
Sonuç
Varsayım yanlış → OT ⊥ teğet doğrudur. ✓
Bu nedenle:
|PA|² = |PO|² - r²
